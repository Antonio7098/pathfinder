# Ops Directory

This directory holds operational notes, reference material, plans, and execution reports for Pathfinder.

This is not the primary product/technical documentation surface. Core implementation and product docs live under `docs/` and the repo root `README.md`.

## Working conventions

- `AGENTS.md` at the repo root is the canonical coding-agent guide.
- phase plans can live at `ops/` root or under a subdirectory if the directory grows further
- add new phase execution writeups under `ops/reports/`
- add rubric-based reviews under `ops/reviews/`
- keep one-off research/reference documents at the `ops/` root unless and until they are archived
- move superseded material into `ops/archive/` rather than deleting history

## Current notable documents

- `ops/VS-rubric - Sheet1.csv` — tracked text version of the VS rubric
- `ops/VS-rubric.xlsx` — spreadsheet version of the VS rubric
- `ops/brief.pdf` — supporting brief/reference material
- `ops/reports/structural-graph-extraction-execution-report.md` — execution report for the completed structural graph phase

- `ops/reviews/templates/vs-rubric-review-template.md` — reusable template for rubric-based reviews
- `ops/reviews/structural-graph-extraction-vs-rubric-review.md` — completed rubric review for the structural graph phase
